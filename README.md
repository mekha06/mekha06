## 🚀 Featured Projects

### 🏟️ EasyGo — AI-Powered Turf Booking Platform
> *Born from a real problem. Built to solve it.*

A complete **MERN stack** application that eliminates the pain of manually calling turf owners to check slot availability. Users discover turfs, book instantly, and pay securely — all in one place.

**Stack:** `React.js` · `Vite` · `Tailwind CSS` · `Node.js` · `Express.js` · `MongoDB Atlas` · `JWT` · `Razorpay`

**Highlights:**
- 🔐 JWT-based authentication with role-based access control (User & Owner)
- 💳 Razorpay payment gateway integration
- 🤖 AI-powered slot recommendations
- 📊 Owner dashboard for real-time booking & turf management
- ☁️ Deployed live on Vercel

### 🤖 Autonomous ML Engineer Agent — Multi-Agent AutoML Platform
> *Upload CSV. Watch the agent think.*

A fully autonomous multi-agent system that takes a raw dataset and delivers a production-ready prediction API — zero manual intervention. I built this while learning ML to eliminate repetitive workflow tasks through intelligent automation.

**Stack:** `Python` · `FastAPI` · `Scikit-learn` · `Pandas` · `NumPy` · `Matplotlib` · `Docker`

**Pipeline:** `Dataset Upload → EDA → Preprocessing → Model Training → Evaluation → Best Model Selection → Prediction API`

**Models Supported:** Linear Regression · Logistic Regression · Decision Tree · Random Forest · Gradient Boosting

**Highlights:**
- 🔍 Automated EDA with visualization generation
- 🏆 Automatic best model selection & feature importance analysis
- 📄 HTML report generation
- 🐳 Dockerized deployment
- 🌐 Live FastAPI prediction endpoint

[![Repo](https://img.shields.io/badge/GitHub-autonomous--ml--agent-181717?style=flat-square&logo=github)](https://github.com/mekha06/autonomous-ml-engineer-agent)
